# 资料与引用

文中每个事实性说法都要能追到这里的一条来源。

状态：`to-read` · `read` · `cited` · `rejected`（不可靠）。

字段：`status`、`kind`（书 / 论文 / 报道 / 数据 / 访谈）、`ref`（出处或链接）、`reliability`（high/medium/low）、
`used-in`（PIECE 编号）、`note`。
